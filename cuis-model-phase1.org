#+title: CUIS SysML Model Definition — Phase 1

This file defines the Phase 1 SysML model for the Common User Interface Server (CUIS).
It follows the MagicGrid tutorial approach: top-level component structure, exchange items,
interface blocks, and high-level behaviour. Deeper internals (sub-component decomposition,
constraints, state machines, sequence diagrams) are in Phase 2.

It is consumed by =sysml-gen.el= to produce the Jython macro that builds the model in MagicDraw.

* DataTypes

Exchange Items (data flowing between CUIS and external actors or between
internal sub-components) are modelled as DataTypes in the ExchangeItems package.
External exchange items carry data across the UF↔CUIS and RTI↔CUIS boundaries.
Internal exchange items flow between CUIS sub-components.

Base types must precede the exchange items that reference them.
